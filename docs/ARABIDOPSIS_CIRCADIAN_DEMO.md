# Arabidopsis Circadian Clock Demonstration

This demonstration shows how Darwin can contribute evidence to a dynamic biological model
without claiming that a signed regulatory graph is itself a kinetic clock model.

## What Darwin supplies

The generator resolves 12 Arabidopsis clock genes by stable locus ID and retrieves the signed,
experiment-backed edges among them from the current GRN Atlas database. In the rebuilt dataset:

- 19 non-self clock edges have measured activation or repression signs.
- All 19 are supported by ATRM and PlantRegMap; four also have DAP-seq support.
- Edge confidence and provenance are retained in `clock_evidence.json`.
- The same genes are submitted to Darwin's generic `network_dynamics` endpoint as a comparison.

The Boolean endpoint reaches a fixed point from the all-ON state. That is a valid result for the
generic signed-network abstraction, but it is not presented as circadian behavior.

## What the separate model supplies

The continuous demonstration uses three functional modules:

1. Morning activity: CCA1, LHY and RVE8.
2. Daytime PRR activity: PRR9, PRR7, PRR5 and ZTL-associated timing.
3. Evening activity: GI, TOC1 and the ELF3-ELF4-LUX evening complex.

They form a compact repressilator:

```text
morning represses evening
evening represses daytime PRR activity
daytime PRR activity represses morning
```

Each module follows the same continuous Hill-repression form. For example:

```text
d(morning)/dt = basal + alpha / (1 + day^hill) - decay * morning
```

The chosen parameters generate a free-running 24.2-hour limit cycle. Gene-level delays spread
the module activities into the established sequence from CCA1/LHY at dawn through PRR9, PRR7,
PRR5, TOC1 and the evening complex. These delays are explicit model assumptions, not fitted
expression measurements.

At hour 24, the perturbation panel clamps the combined morning module high. This is a qualitative
CCA1-overexpression proxy, and its loss of rhythmicity is consistent with the known CCA1-OX
phenotype. Because the compact model groups CCA1 and LHY, it is not a genotype-exact prediction.

## Reproduce

```bash
backend/venv/bin/pip install -r backend/requirements-dev.txt
backend/venv/bin/python backend/scripts/generate_circadian_demo.py
```

The command writes the public demonstration to `public/circadian-clock-demo/`:

- `index.html`: explanatory public page.
- `clock_demo.gif`: two-day animated network and trajectories.
- `clock_demo.png`: static wild-type and perturbation comparison.
- `clock_timeseries.csv`: model trajectories for all 12 genes.
- `clock_evidence.json`: atlas edges, provenance, assumptions and Boolean comparison.

## Truth Boundary

GRN Atlas supports the gene identities and solid regulatory edges shown in the network. The
continuous trajectories are generated by the separate explanatory model. They demonstrate why
time delays and feedback are necessary, but they do not establish that GRN Atlas inferred kinetic
parameters, quantitative expression, or a circadian period from sequence or signed edges alone.
